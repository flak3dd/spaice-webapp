Frequently Asked Questions

Got Questions? We’ve Got Answers.

How does a six-character code securely encrypt my files?

SpaceDrop passes your 6-character code into PBKDF2 with SHA-256 for 120,000 computational rounds using a cryptographic salt. This produces 512 bits: the first 256 bits serve as the local AES-GCM encryption key, while the remaining bits yield a public lookupId. The encryption key never leaves your device, so anyone intercepting the lookup ID cannot open your drop without the 6-character code.

Can the server or administrators view my drops or photos?

No. Because all encryption and decryption occurs exclusively in your browser or native Mac app, the relay server only receives opaque binary ciphertext. The server has no access to the keys, plaintext filenames, or payload contents.

What is a Space versus a Drop?

A Drop is a point-to-point one-time transfer: the first person to claim the 6-character code downloads the files and the drop is immediately destroyed. A Space is a multi-user ephemeral room that stays alive for 24 hours after the last post, allowing everyone with the code to post notes and share unsealable files in real time.

What are the file size and item limits?

Drop codes carry up to 24 files per batch, with a maximum per-file size of 50 MB and a total batch limit of 96 MB. Files are sliced into 512 KB chunks for resilient background uploading and streaming.
